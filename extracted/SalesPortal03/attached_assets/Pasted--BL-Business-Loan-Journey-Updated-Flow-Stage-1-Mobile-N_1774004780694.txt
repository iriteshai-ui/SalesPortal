
BL Business Loan Journey – Updated Flow

Stage 1 – Mobile Number + Consent

What happens in this stage:
	•	Customer enters mobile number
	•	Capture customer consent immediately
	•	Remove consent logic from Stage 2 (consent exists only in Stage 1)

⸻

Stage 2 & Stage 3 – No Change
	•	No updates required

⸻

Stage 4 – Offer Simulation

Before showing the offer screen:
	•	Show a 5-second loader with message:
“Fetching best offer for you…”

After loader, display 3 offer categories:
	1.	Reject Segment
	•	Show Rejection Screen
	•	End journey
	2.	Blue Segment
	•	Show only Loan Amount (highlighted in blue)
	•	Remove sliders, PF, Stamp Duty, etc.
	•	These details will be shown in Stage 6
	3.	Yellow Segment
	•	Check BRP Flag:
	•	If Yes → Go to Stage 6 (Banking Verification)
	•	If No → Continue to Blue flow
	4.	Green Segment
	•	Same logic as Yellow:
	•	If BRP Flag = Yes → Stage 6
	•	Else → Continue flow

⸻

Stage 5 – BRP (Business Rule Processing)
	•	No changes required

⸻

Stage 6 – Account Aggregator (AA) / Banking Verification

Available CTAs for Agent:

6.1 Send Link to Customer
	•	Send AA link to registered mobile number

6.2 Self Banking Verification (Agent)
	•	Clicking “Start Banking Verification” opens a new tab (mock: google.com)
	•	Original tab shows waiting screen

6.3 Waiting Screen
	•	Message: “Waiting for Banking Eligibility…”
	•	Minimum wait time: 10 seconds

6.4 Retry / Error Handling
	•	If verification fails → Show Retry Screen with error message

6.5 Rejection Screen
	•	If AA eligibility fails → Show Rejection Screen

6.6 Actual Offer Screen (AA Offer)
	•	If verification is successful:
	•	Show AA-based actual offer with full financial details
	•	CTA: “Want More” → Goes to Stage 7 (optional)

⸻

Stage 7 – GST Based Offer (Want More Journey)

When user clicks “Want More”:
	•	Send link to customer again
	•	Load simulator → Check Best Offer (e.g., up to ₹7–10 Lakhs)
	•	Freeze AA/Banking offer for 10 seconds

After freeze:
	•	Show: Offer Found / Reject CTA

Then display:
	•	GST-based offer with slider
	•	Full financial details based on GST income

⸻

Stage 8 – Additional Details Screen

Mandatory fields:
	•	Purpose of Loan
	•	Father’s Name
	•	Marital Status
	•	Email ID + OTP Verification
	•	RM ID (Agent tagging)
	•	DocOnline Option
	•	Business Address Proof Upload
	•	OHP Document Upload

CTA:
	•	Submit & Send KYC Link

⸻

Stage 9 – KYC Status
	•	Show simulator:
	•	KYC Approved / KYC Failed
	•	Mark stage as Success / Failed

⸻

Stage 10 – Field Investigation (FI)
	•	Display FI status after KYC approval

⸻

Stage 11 – Final Offer Stage (Timeline View)

Display all steps in a timeline format (for UAT):

Agent can mark each as Completed:
	•	Final Offer Summary
	•	KFS (Key Fact Statement)
	•	Penny Drop Verification
	•	eNACH
	•	eSign

CTA:
	•	Send Link to Customer
